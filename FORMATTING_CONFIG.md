# Конфигурация форматирования кода

## Настройка длины строки

Все инструменты форматирования настроены на **88 символов** для единообразия:

### Black
- **Файл**: `pyproject.toml`
- **Настройка**: `line-length = 88`
- **Описание**: Black автоматически форматирует код с длиной строки 88 символов

### Flake8
- **Файл**: `.flake8`
- **Настройка**: `max-line-length = 88`
- **Описание**: Flake8 проверяет длину строк (E501 игнорируется, так как Black уже форматирует)

### Pylint
- **Файл**: `pyproject.toml`
- **Настройка**: `max-line-length = 88`
- **Описание**: Pylint проверяет длину строк

## Почему 88 символов?

- Стандарт Black по умолчанию
- Хороший баланс между читаемостью и использованием пространства экрана
- Соответствует рекомендациям PEP 8 (до 99 символов)

## Игнорируемые ошибки Flake8

- **E203**: whitespace before ':' (конфликт с Black)
- **E266**: too many leading '#' (конфликт с Black)
- **E501**: line too long (Black уже форматирует)
- **W503**: line break before binary operator (конфликт с Black)

## Проверка форматирования

```bash
# Проверить форматирование (без изменений)
black --check .

# Автоматически исправить форматирование
black .

# Проверить с Flake8
flake8 .
```
